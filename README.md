# CAFE AROMA
Aroma Café es una pagina web desarrollada para presentar una cafetería y sus productos.

## Funciones
- Mostrar información sobre la cafetería.
- Mostrar los productos disponibles junto con sus precios.
- Mostrar información de contacto.
- Permitir al usuario completar un formulario con sus datos.

## Tecnología 
- HTML
- CSS
